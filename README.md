# 수업공유 (Class Share)

수업 중 선생님 화면에서 학생들에게 텍스트, 링크, 코드, 파일을 실시간으로 공유하는 웹 애플리케이션입니다.

## 주요 기능
- **선생님 화면 (`/:code?teacher=...`)**: 학생 접속용 QR 코드 및 단축 주소 생성, 텍스트/링크/코드/파일(최대 50 MB) 공유, 실시간 접속 인원(`접속 N명`) 확인, 방 이름 변경 및 삭제
- **학생 화면 (`/:code`)**: 선생님이 올린 내용을 새로고침 없이 실시간으로 확인하고 버튼 한 번으로 복사/다운로드

## 로컬 실행 방법
```bash
npm install
npm run dev
```

## Vercel 배포 시 필수 환경 변수
GitHub 저장소에 업로드한 뒤 Vercel에서 Import할 때 아래 두 환경 변수를 설정하세요.
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`
